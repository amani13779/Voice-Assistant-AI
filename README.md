# 🎙️ Voice Assistant AI

A simple Python-based voice assistant that listens to voice commands, processes user requests, and responds with synthesized speech.

---

## 🚀 Features

- Speech-to-Text (STT)
- Text-to-Speech (TTS)
- Open Google and YouTube
- Search Wikipedia
- Tell the current time and date
- Voice interaction

## 🛠️ Requirements

- Python 3.13.5
- SpeechRecognition
- PyAudio
- gTTS
- pygame
- wikipedia

Install the required packages:

```bash
pip install -r requirements.txt
```

---

## ▶️ Run

```bash
python main.py
```
